# Stoicheia: Euclid's Elements, checked line by line in Lean

*The plan this project started from (15 October 2026), kept as written. Where it differs from the code, the code is right.*

*Edited for publication: scoping notes and local details removed; on 19 October 2026 the owner's name was replaced by the role ([decisions](0002-decisions.md)).*

## Context

A public project, free for anyone to use: carry a 2,300-year-old book into Lean. The repo presents **all 13 books** of Euclid's Elements (465 propositions). Each proposition gets:
- Euclid's actual words;
- a Lean proof that follows Euclid's argument step by step;
- a machine-generated **certificate** of what it rests on;
- a **mishnah**: layered commentary, including the modern view (ℝ², vectors, complex numbers, matrices), as prose only.

**Tone**: friendly and welcoming, generous with credit to everyone whose work this stands on. It is not a competition with prior projects.

Constraints:
- "No fancy tricks": no coordinates, no complex numbers, no analytic geometry in the proofs. Simple geometry Abe Lincoln would recognize.
- Read like the Elements, and follow Euclid wherever possible.
- Present everything as Markdown on GitHub.
- Plain Lean 4.35, no Mathlib, plain-English comments, teaching `#print axioms`.

Decided:
- Name: **stoicheia** (Στοιχεῖα, Euclid's Greek title).
- Repo: `jackChallis/stoicheia`, public.

## The page for one proposition (`book/I/01.md`, generated)

1. **Enunciation**: Heath's 1908 text.
2. **Figure**: SVG using Heath's lettering.
3. **Euclid's proof**: Heath's 1908 text, in full.
4. **In Lean**: the theorem, with each Heath sentence as a `--` comment above the Lean step(s) it licenses.
5. **Certificate line**:
   - "Euclid cites" (Heath's bracketed references) beside "Lean needs" (computed).
   - Rests on: Postulates, Common Notions, named tacit assumptions.
6. **Mishnah**:
   - Proclus (Book I only; Taylor's 1792 translation, Gutenberg #74253/#79455).
   - Heath's 1908 notes.
   - Our notes: what Euclid assumed silently and how Lean exposes it. Then "the modern way": e.g. I.1's apex is a 60° rotation, a one-line complex-number fact.

## Architecture (validated by a prototype compiled with Lean 4.35)

- **Plain Lean 4.35.0, zero dependencies.** `lakefile.toml`. With no Mathlib, every crew worktree builds in seconds.
- **Undefined terms are `opaque`; assumptions are top-level `axiom`s.** Terms: `Point`, `Line`, `Circle`, `OnLine`, `Between`, `SameSide`, … Axioms: Postulates 1–5, Definition 15, tacit rules, superposition. `#print axioms` then lists exactly Euclid's assumptions; the prototype confirmed it on I.1.
- **Magnitudes are one indexed family** `Magnitude (k : Kind)`, with kinds length, angle, area and solid.
  - CN3 (cancellation) and CN5 are real axioms, so they are reported exactly.
  - CN1, CN2 and CN4 are Lean logic. They become named theorems, and the certificate reports them when a proof cites them by name.
  - `a < b` means "a is part of b".
- **Definition 10 and Postulate 4.** Def. 10 is a predicate, and Postulate 4 is the axiom that all right angles equal `∟`. This keeps Postulate 4's use visible.
- **Tacit assumptions are added only when a proof needs one.**
  - Each docstring cites its System E section and rule.
  - Area rules are adapted, with MIT attribution, from LeanEuclid.
  - Each rule is tagged **neutral** or **euclidean-only**.
- **Figures keep proofs readable.** Each proposition declares `structure FigureN`, holding the facts Euclid reads off the diagram.
  - These facts are proved by a `figure` tactic (core `grind` over the tagged tacit rules) or by hand.
  - The main proof cites them as `fig.C_inside_ABG`.
  - `grind` is allowed only in figure proofs.
  - Field docstrings feed the mishnah's "what Euclid saw but never said" list.
  - Expect 60–100 tacit axioms and 100–200 "Book Zero" lemmas for plane geometry.
- **Four foundations, each with a design brief in `docs/briefs/` before any code.**
  1. **Plane** (I–IV, VI; constructions in X and XIII): System E-derived.
  2. **Magnitude and proportion** (V; used by VI, X, XII): Eudoxus's Def. V.5 taken literally, and Def. V.4 (Archimedean) as an axiom. Flag the fourth-proportional existence that V.18 assumes without proof.
  3. **Numbers** (VII–IX): Book VII states no axioms, so the brief decides what Euclid assumes. Euclid proves ab = ba in VII.16, so `Nat.mul_comm` must not be used before it.
  4. **Solid** (XI–XIII): a 3D synthetic framework with planes as primitives. XII's exhaustion arguments run on X.1.
- **Statements.**
  - Problems are `∃ …` theorems; theorems are implications.
  - Names are `Elements.BookI.Prop1`, with the docstring equal to Heath's enunciation.
  - I.47 uses no multiplication: squares are areas.

## The crew: proving in parallel

**Why it parallelizes.** A Lean proof depends only on the *statements* of the propositions it cites, not on their proofs. Once a book's statements are frozen (with `sorry`), every proposition in it can be proved at the same time. The certificate shows "rests on a sorry" until the cited proofs land. Whole books run in parallel too:

| Track | Path |
|---|---|
| Plane | I → II–IV → VI |
| Proportion | V (independent of I–IV) |
| Numbers | VII–IX (independent of geometry) |
| Solid | XI–XIII (its brief can start anytime) |

**Ranks.** Each rank writes only its own files, so nothing collides.

| Rank | Who | Owns (sole writer) | Job |
|---|---|---|---|
| **Captain** | Main Claude session, with the owner | `Elements/Foundations/` (every axiom), policies, merges, generated files, releases | Approves new tacit axioms, freezes statements, regenerates the certificate, pushes |
| **First mate** | One agent per book or foundation | That book's statements, `heath/` text, tranche plan | Writes statements plus Heath sketches; reviews faithfulness ("does the Lean say what Euclid says?") |
| **Bosun** | One agent per tranche (6–8 props) | That tranche's `Elements/Figure/` lemmas | Builds and checks the tranche; consolidates requests from sailors; sends failures back |
| **Sailor** | One agent per proposition, in its own git worktree | `PropNN.lean`, `figures/…/NN.svg`, `mishnah/…/NN.md` | Proves the proposition following Heath's sentences. Never adds axioms. Returns a structured report: done or blocked, tacit facts needed, gaps found in Euclid |

**A voyage** is one tranche, run with the Workflow tool.
1. Sailors work in parallel, in a pipeline: each sailor's proof goes on to the bosun's build check as soon as it is done.
2. Each proof gets an adversarial faithfulness review with two lenses:
   - the statement versus Heath;
   - the proof versus Euclid's route: no shortcuts through later propositions or bypass lemmas. This criterion is credited to Pistis.
3. Barrier: requested tacit facts are deduplicated. The captain adds the approved ones in a single commit.
4. Blocked sailors retry.
5. The captain merges the sailor branches (their files don't overlap), regenerates, and pushes.

Every voyage appends to `docs/reports/crew/`: attempts, hours, axioms added, gaps found.

## Certificate, graph, and checks (CI fails on any violation)

**Generators**
- `lake exe facts` → `facts.json`. It uses `Lean.collectAxioms` plus a dependency walk that stops at other propositions; validated in the prototype.
- `scripts/render.py` (Python standard library only) builds:
  - `book/**/NN.md`;
  - `CERTIFICATE.md`: per-book tables plus computed headlines such as "I.1–I.28 never use Postulate 5";
  - `GRAPH.md`: a Mermaid graph per book plus a book-to-book graph.

**Policy checks**
- No `axiom` outside `Foundations/`.
- Only I.4 and I.8 may cite `Superposition`.
- No euclidean-only tacit rule before I.29.
- Book Zero lemmas never cite a proposition.
- No `native_decide`.
- **Fidelity**: the joined `--` comments must equal the Heath text.
- Generated files must be fresh: `git diff --exit-code` after regeneration.

## Text, figures, licensing

- **Text**: Heath 1908, *The Thirteen Books of Euclid's Elements*, public domain. Transcribe from the archive.org / HathiTrust scans, proofreading the OCR against the page images. Perseus is a cross-check only. Casey 1885 (Gutenberg #21076) is a reference for I–VI.
- **Figures**: our own SVGs with Heath's letters.
- **Licenses** (anyone can use it): code Apache-2.0; our prose CC BY 4.0; Heath and Proclus marked public domain. LeanEuclid's MIT attribution goes in `NOTICE`.

## Friendly by design (clearly not competitive)

- **The README thanks people before it explains anything.** Near the top: "This is a companion to the people who formalized Euclid before us, not a replacement. If you want X, see their project." Each project is described by what it does well, in its own words where possible (quote the abstracts).
- **No "first", "only" or "better" anywhere public.** No "unlike X", no claims about coverage. The comparisons in this plan stay in `docs/reports/0001-prior-art.md`, written neutrally.
- **Every proposition page has "Also formalized in"**, with links to the same proposition in LeanEuclid (`Book/PropNN.lean`), synthetic_euclid_4, GeoCoq/Beeson and Pistis, where they exist. A small mapping table drives it, and readers are sent to the others' work.
- **Credit on every page.** Mishnah notes and the gap catalogue credit whoever found a gap first (Proclus, Heath, Beeson et al., Pistis's 52), and our new finds are marked as new. Tacit axioms cite System E, and adapted code cites LeanEuclid.
- **Easy to cite.** `CITATION.cff` gives a way to cite us. `docs/references.bib` holds full BibTeX for everyone we build on, and `NOTICE` covers reused code (LeanEuclid, MIT).
- **Optional heads-up before going public.** Claude drafts short, warm notes to the LeanEuclid/Pistis group (Xujie Si) and to Hernández-Espiet/Kontorovich, along the lines of "we loved your work, we're building a reader's edition, we link to you on every page, and you're welcome to join in". The owner reviews and sends them; Claude never sends anything itself.
- **Open door.** `CONTRIBUTING.md` invites anyone, including those authors, to add commentary, a figure or a proof.

## Session 1 (M0) steps

1. Create the repository (`git init`; plain `lake init`; toolchain v4.35.0).
2. Commit this plan as `docs/briefs/0001-plan.md`, and the prior-art and sources research as `docs/reports/0001-prior-art.md`.
3. **Foundations**: Words, Magnitudes, Book I Definitions, Postulates 1–5, Common Notions, Superposition, and the tacit rules I.1–I.3 need. Start from the prototype.
4. **Heath text**: Book I front matter (23 definitions, 5 postulates, 5 common notions) and I.1–I.48, transcribed into `heath/I/`.
5. **Lean**: `Prop01`–`Prop48` with statements, Heath sentences as comments, and `sorry`. Then freeze the Book I statements. Prove I.1–I.3 by hand.
6. **Tooling**: the certificate exe, `render.py`, `check_fidelity.py`, and CI.
7. Figures and mishnah for I.1–I.3, plus a front-matter page that pairs each definition, postulate and common notion with its Lean declaration.
8. **README**: thanks and companion framing first; then how to read a page; how to run it; "try breaking it"; how to join in; Credits; licenses. Also `CITATION.cff`, `docs/references.bib`, `CONTRIBUTING.md`, the "Also formalized in" mapping for Book I, and draft heads-up notes in `docs/outreach/` for the owner to send.
9. Before pushing, run a tone pass: check README and pages for "first", "only", "unlike" or "better", and check every citation and link. Then `gh repo create jackChallis/stoicheia --public --source . --push` and check CI is green.
10. **Shakedown voyage**: the crew workflow on tranche I.4–I.8. Merge, regenerate, push, and log it.

## Verification

- `lake build` succeeds. The only `sorry` warnings are on propositions the certificate marks unproved.
- `#print axioms Elements.BookI.Prop1` lists only Postulates 1 and 3, Definition 15, named tacit rules and `Classical.choice`.
- `lake exe facts && python3 scripts/check_fidelity.py && python3 scripts/render.py && git diff --exit-code` passes, both locally and in Actions.
- **Negative tests**, each run once and then reverted:
  - an euclidean-only rule used in I.16 makes CI fail;
  - an edited Heath sentence makes the fidelity check fail;
  - a broken proof makes the build fail.
- **Crew**:
  - each sailor branch touches only its own files;
  - the merged result builds;
  - the faithfulness reviewer rejects a planted shortcut proof.
- **On GitHub**: `book/I/01.md` reads text → figure → proof → Lean → certificate → mishnah. `GRAPH.md` renders, and `CERTIFICATE.md` shows I.1–I.8 as proved after the shakedown.

# alias, each with the owner's approval; the release notes list them as removed, and the list
# is kept here until the notes are written (#702). scripts/check_released_names.py accepts a
# name that tests/released_names.txt holds and main lacks only when it has a row here, and a
# row only when its name is one the list's tag declares and main does not, and its decision
# entry exists, names it in backticks, and has one paragraph that says "the owner" and holds
# the row's words between quotation marks. A row, one for each name, with no blank line:
#     removed <name> docs/decisions/<YYYY-MM-DD>-<slug>.md <the owner's words, as quoted>
# A row is added in the pull request that removes its name, and the list is emptied in the
# pull request that commits tests/released_names.txt made at the next release's tag.
